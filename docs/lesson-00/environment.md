# Lesson 00 - Development Environment

## Overview

This document describes the development environment used for the Operating Systems Laboratory project.

The purpose of this laboratory is to create a stable and reproducible environment for learning operating systems, low-level programming, networking, and system development.

## Host Environment

The primary development environment is a Linux virtual machine.

Current platform:

* Operating System: Ubuntu 24.04 LTS
* Virtualization: Virtual Machine environment
* Shell: Bash
* Version Control: Git
* Repository Hosting: GitHub

## Development Philosophy

The environment is designed around the following principles:

* Use Linux as the primary systems development platform.
* Practice real engineering workflows.
* Keep all experiments documented and version controlled.
* Prefer understanding fundamentals over using automated solutions.

## Required Tools

The laboratory will gradually use:

* Git
* GCC toolchain
* GNU Make
* Assembly tools
* Debugging tools
* QEMU virtualization
* Network analysis tools

## Future Expansion

This environment will evolve as the laboratory progresses toward:

* Boot process experiments
* Kernel development
* Memory management experiments
* Process management
* Networking subsystem exploration
* Embedded system development
