# Lesson 00 - Learning Notes

## Introduction

Lesson 00 establishes the foundation of the Operating Systems Laboratory project.

The primary focus is not yet operating system implementation, but preparing the engineering workflow required for future development.

## Main Lessons

### 1. Repository Design

A professional project requires a clear structure.

The repository separates:

* documentation,
* laboratory experiments,
* source code,
* scripts,
* references.

### 2. Documentation as Engineering Practice

Documentation is part of development, not an afterthought.

Every important decision should have a written explanation.

### 3. Version Control Thinking

Git provides a timeline of project evolution.

The history should explain:

* what changed,
* why it changed,
* and how the project progressed.

## Future Learning Path

After establishing this foundation, future lessons will focus on:

* computer architecture,
* boot process,
* assembly programming,
* operating system concepts,
* kernel development,
* networking systems.
