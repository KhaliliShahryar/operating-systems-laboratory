# Books

This document records books used or planned as references for the Operating Systems Laboratory.

## Operating Systems

### Operating Systems: Three Easy Pieces

Remzi H. Arpaci-Dusseau and Andrea C. Arpaci-Dusseau.

A practical introduction to operating-system concepts, particularly useful for understanding:

* processes,
* virtualization,
* concurrency,
* persistence,
* memory management,
* file systems.

This book will be used as an important conceptual reference during the laboratory.

### Modern Operating Systems

Andrew S. Tanenbaum.

A broad reference covering operating-system architecture and fundamental concepts.

It is useful as a secondary reference when a deeper theoretical treatment is required.

## Computer Architecture

Future references will include processor architecture documentation and textbooks covering:

* instruction execution,
* memory hierarchy,
* interrupts,
* privilege levels,
* I/O,
* processor architecture.

## Networking

Future references will include material covering:

* TCP/IP,
* Ethernet,
* routing,
* network operating systems,
* network interfaces,
* Software Defined Networking.

## Reference Policy

References are recorded because they contribute to the laboratory's understanding or implementation.

The repository does not attempt to reproduce copyrighted material. It records bibliographic information and explains how each reference contributes to the project.
