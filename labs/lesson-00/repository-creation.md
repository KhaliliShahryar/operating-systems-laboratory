# Lesson 00 Lab - Repository Creation

## Objective

Document the creation of the initial Operating Systems Laboratory repository.

---

# Repository Purpose

The repository is designed as a long-term engineering portfolio covering:

* operating systems,
* computer architecture,
* networking,
* low-level programming.

---

# Initial Structure

The repository was organized into:

```text
operating-systems-laboratory

├── docs
├── labs
├── src
├── scripts
├── references
├── README.md
└── LICENSE
```

---

# Design Reasoning

The structure separates different responsibilities:

## docs

Contains explanations, decisions, and learning records.

## labs

Contains practical experiments and verification steps.

## src

Reserved for future implementation work.

## scripts

Reserved for automation tools.

## references

Contains external learning resources.

---

# Result

The project now has a scalable structure suitable for future operating system development experiments.
